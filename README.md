# Biblioteca digital

Primer parcial de Programación Web. Aplicación de una sola página (HTML, CSS y JavaScript) para gestionar un catálogo de libros, préstamos, historial y ajustes, con persistencia en `localStorage`.

**Autor:** Cesar Emilio Caro Carrillo

## Estructura
- `index.html`: estructura semántica, cuatro vistas y modales.
- `css/styles.css`: estilos, tema claro/oscuro, diseño responsivo, transiciones y animaciones.
- `js/datos.js`: datos iniciales y utilidades de fechas.
- `js/logica.js`: reglas de negocio, sin acceso al DOM.
- `js/app.js`: interfaz construida a partir de los datos.

## Uso
Abrir `index.html` en el navegador. No requiere dependencias.
